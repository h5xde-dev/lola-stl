# lola.stl — прототип магазина

Кликабельный прототип магазина STL-моделей: каталог, корзина с акциями «2+1» и «1+1», оформление, «Мои покупки», вид Telegram Mini App и админка (модели, цены и акции, заказы).

Это статический сайт: одна страница `public/index.html`, без сборки и без сервера. Оплата, выдача файлов и чеки в нём имитируются. Данные хранятся только в браузере посетителя (`localStorage`), кнопка «Сбросить демо» возвращает всё к началу.

## Запуск локально

```bash
npm run dev
```

Откройте http://localhost:3000. Можно и без npm: `python3 -m http.server 3000 -d public`.

## Публикация на Vercel

Первый раз (войти в аккаунт и привязать проект):

```bash
npx vercel login
npx vercel
```

На вопросы CLI: проект новый, папка — текущая, настройки сборки оставить по умолчанию (`vercel.json` уже указывает папку `public`). Команда выдаст ссылку на превью.

Публикация на основной адрес:

```bash
npm run deploy:prod
```

Другой вариант: залить папку в GitHub-репозиторий и импортировать его на vercel.com — каждый пуш будет публиковаться автоматически.

## Что учесть

- Прототип закрыт от поисковиков: `noindex` в `<head>` и заголовок `X-Robots-Tag` в `vercel.json`.
- Реквизиты ИП, оферта и политика в подвале — заглушки.
- Админка открывается без пароля. Для показа клиенту это нормально, для настоящего магазина — нет.
